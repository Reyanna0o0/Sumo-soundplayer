# Sumo v0.1.2 · build 35

[简体中文](../../RELEASE_0.1.2.md) · [繁體中文](../zh-Hant/RELEASE_0.1.2.md) · [English](../en/RELEASE_0.1.2.md) · **日本語** · [한국어](../ko/RELEASE_0.1.2.md)

**正式版。** クリエイターのアバター切り抜きと、写真選択画面の安定性改善を含みます。

## ダウンロードと更新

**[build 35 の IPA をダウンロード](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/download/v0.1.2/simo-0.1.2-build35-unsigned.ipa)**

**iOS / iPadOS 18 以降**が必要です。

1. パソコンでリンクを開き、取得した IPA を「ダウンロード」フォルダで確認します。
2. 初回は[インストール手順](INSTALL.md)を参照してください。更新時は元の署名方法で上書きし、**先に旧版を削除しないでください**。

**build 35 を使用中なら再インストールは不要です。** 正式版はプレビューと同じ IPA で、アプリやデータベースの追加変更はありません。[ダウンロードの案内](DOWNLOAD.md)

## アバターの切り抜き

- クリエイター編集画面で写真またはファイルからアバターを選ぶと、「アバターを切り抜く」が開きます。
- ドラッグで位置を調整し、ピンチまたはスライダーで拡大・縮小できます。円形の枠で表示範囲を確認でき、リセットで最初の中央位置に戻ります。
- 「使用」を押してからクリエイターを保存します。切り抜きをキャンセルすると現在のアバターを維持し、編集画面全体をキャンセルすると今回の変更を破棄します。
- このアバターを引き継ぐクリエイターのカバーや通話表示にも、選んだ範囲が使われます。作品カバーは従来どおり 4:3 です。

## 検証範囲

- 端末向け・シミュレーター向けの Release ビルド、リソース、アプリの 5 言語文言を検証済みです。
- シミュレーターで選択、キャンセル、ドラッグ、ピンチ、スライダー、リセット、保存、連続置き換え後のキャンセルを確認しました。アプリ内で動かす検証では、切り抜く内容、正方形出力、4:3 カバーとの互換性、アバターの継承、下書きの削除を確認しました。
- 独立したシミュレーターと合成データを使用し、利用者の実機は操作していません。ファイル選択も同じ切り抜き処理を使いますが、システムのファイル画面で閲覧・選択してから切り抜く一連の操作は未検証です。古い写真、iCloud ダウンロード、外部ファイルサービス、iPad のレイアウトにも実機確認が必要です。
- コア 3755 項目と選択セッション 9 項目の検証は build 34 の記録です。build 35 ではコアやデータベース構造を変更せず、アバター切り抜きを追加検証しました。[詳細な検証記録（簡体字中国語）](../../RELEASE_STATUS.md)
