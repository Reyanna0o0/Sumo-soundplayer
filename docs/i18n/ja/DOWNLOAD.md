# Sumo をダウンロード

[简体中文](../../DOWNLOAD.md) · [繁體中文](../zh-Hant/DOWNLOAD.md) · [English](../en/DOWNLOAD.md) · **日本語** · [한국어](../ko/DOWNLOAD.md)

**[IPA をダウンロード · v0.1.2（build 35）](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/download/v0.1.2/simo-0.1.2-build35-unsigned.ipa)**

**iOS / iPadOS 18 以降**が必要です。Windows または Mac でダウンロードしてください。GitHub アカウントは不要です。

## 3 つの手順

1. **上のリンクをクリック**し、ダウンロードが終わるまで待ちます。
2. **ファイルを確認します**。「ダウンロード」フォルダにある `simo-0.1.2-build35-unsigned.ipa` を探してください。ブラウザのダウンロード一覧から「フォルダーに表示」「Finder に表示」を選んでも開けます。
3. **署名してインストールします**。IPA を Sideloadly にドラッグし、[インストール手順](INSTALL.md)に従ってください。`unsigned` は未署名という意味で、インストール用ツールが署名を行います。

**すでにインストール済みの場合**は、同じ Apple Account、署名ツール、アプリ識別子で上書きしてください。**先に旧版を削除しないでください。** build 35 を使用中なら、再インストールは不要です。

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| リンクを押しても反応しない・ダウンロードに失敗する | ブラウザの一覧を確認して再試行します。[リリースページ](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/tag/v0.1.2)の `Assets` から `.ipa` で終わるファイルを選ぶこともできます |
| ダウンロードしたファイルが見つからない | ブラウザのダウンロード一覧で「フォルダーに表示」「Finder に表示」を選びます |
| IPA をダブルクリックしてもインストールできない | Sideloadly にドラッグし、[インストール手順](INSTALL.md)を進めてください |
| スマートフォンにダウンロードしてしまった | この Sideloadly の手順にはパソコンが必要です。パソコンで同じリンクを開いてください |

解決しない場合は、端末とエラー内容を添えて[不具合を報告](https://github.com/Reyanna0o0/Sumo-soundplayer/issues/new?template=bug-report.yml)してください。報告テンプレートは簡体字中国語です。
