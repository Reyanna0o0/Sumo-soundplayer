## 創作者頭像裁剪

- 在創作者編輯頁從照片或檔案選取頭像後，會開啟「裁剪頭像」。
- 拖曳調整位置，雙指或滑桿縮放；圓形框預覽頭像範圍，「重設」回到初始置中範圍。
- 點「使用」後再儲存創作者。取消裁剪保留目前頭像；取消整個編輯頁則放棄本次修改。
- 繼承創作者頭像的封面或通話外觀，也會使用所選範圍；作品封面仍採原有 4:3 裁剪。

## 驗證範圍

- 完整裝置版與模擬器版 Release 建置、資源核對及五語 App 文案檢查通過。
- 模擬器界面檢查涵蓋選圖、取消裁剪、拖曳、雙指與滑桿縮放、復位、儲存、連續替換與取消編輯。App 內執行的檢查確認實際裁剪內容、正方形輸出、4:3 封面相容、頭像繼承與草稿清理。
- 使用獨立模擬器及合成資料，未操作使用者手機。檔案入口共用裁剪流程，但系統檔案瀏覽選取至裁剪的完整界面鏈路仍未驗證。較舊照片、iCloud 下載、第三方檔案服務與 iPad 版面仍需實機檢查。
