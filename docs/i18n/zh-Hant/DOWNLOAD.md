# 下載廝磨安裝包

[简体中文](../../DOWNLOAD.md) · **繁體中文** · [English](../en/DOWNLOAD.md) · [日本語](../ja/DOWNLOAD.md) · [한국어](../ko/DOWNLOAD.md)

**[點擊下載 IPA · v0.1.2（build 35）](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/download/v0.1.2/simo-0.1.2-build35-unsigned.ipa)**

適用於 **iOS / iPadOS 18 或更新版本**。請在 Windows 或 Mac 電腦上下載，無需登入 GitHub。

## 三步完成

1. **點擊上方下載連結**，等待瀏覽器顯示下載完成。
2. **找到安裝包**：在「下載 / Downloads」資料夾找到 `simo-0.1.2-build35-unsigned.ipa`，也可在瀏覽器下載清單中點「在資料夾中顯示」或「在 Finder 中顯示」。
3. **簽名安裝**：將 IPA 拖入 Sideloadly，依照[安裝教學](INSTALL.md)完成。`unsigned` 表示尚未簽名，由安裝工具處理即可。

**更新現有 App 時**，請沿用原 Apple 帳號、簽名工具與 App 識別碼覆蓋安裝，**請勿先移除舊版**。已經安裝 build 35 的使用者無需重裝。

## 遇到問題

| 情況 | 處理方法 |
| --- | --- |
| 點連結沒有反應或下載失敗 | 查看瀏覽器下載清單並重試；也可開啟[版本頁](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/tag/v0.1.2)，在 `Assets`（附件）選取以 `.ipa` 結尾的檔案 |
| 找不到下載好的檔案 | 在瀏覽器下載清單點「在資料夾中顯示」或「在 Finder 中顯示」 |
| 連按兩下 IPA 無法安裝 | 將它拖入 Sideloadly，再依照[安裝教學](INSTALL.md)操作 |
| 檔案下載到了手機 | 這套 Sideloadly 安裝流程需要電腦；在電腦上開啟同一連結下載即可 |

需要協助時，可[回報問題](https://github.com/Reyanna0o0/Sumo-soundplayer/issues/new?template=bug-report.yml)，說明裝置與錯誤訊息。問題範本目前為簡中。
