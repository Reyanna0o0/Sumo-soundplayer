兩個版本均為未簽名 IPA，需要自行簽名安裝；這是同一 App 的兩個版本選項。

**新版為測試版。還原備份會替換目前整個媒體庫，不會合併。完整真機還原與家庭 NAS 使用仍未完成驗收。** 請保留重要原始檔案與現有 App。[測試版範圍與限制（簡中）](../../RELEASE_BUILD38.md)

適用於 **iOS / iPadOS 18 或更新版本**。請在 Windows 或 Mac 電腦上下載，無需登入 GitHub。

## 三步完成

1. **在上方選擇版本並點擊對應 IPA 連結**，等待瀏覽器顯示下載完成。
2. **找到所選版本的 `.ipa` 安裝包**：查看「下載 / Downloads」資料夾，或在瀏覽器下載清單點「在資料夾中顯示」「在 Finder 中顯示」。
3. **簽名安裝**：將 IPA 拖入 Sideloadly，依照[安裝教學](INSTALL.md)完成。`unsigned` 表示尚未簽名，由安裝工具處理即可。

**更新現有 App 時**，請沿用原 Apple 帳號、簽名工具與 App 識別碼覆蓋安裝，**請勿先移除舊版**。

## 遇到問題

| 情況 | 處理方法 |
| --- | --- |
| 點連結沒有反應或下載失敗 | 查看瀏覽器下載清單並重試；也可開啟[版本頁](https://github.com/Reyanna0o0/Simo-soundplayer/releases)，在 `Assets`（附件）選取以 `.ipa` 結尾的檔案 |
| 找不到下載好的檔案 | 在瀏覽器下載清單點「在資料夾中顯示」或「在 Finder 中顯示」 |
| 連按兩下 IPA 無法安裝 | 將它拖入 Sideloadly，再依照[安裝教學](INSTALL.md)操作 |
| 檔案下載到了手機 | 這套 Sideloadly 安裝流程需要電腦；在電腦上開啟同一連結下載即可 |

需要協助時，可[回報問題](https://github.com/Reyanna0o0/Simo-soundplayer/issues/new?template=bug-report.yml)，說明裝置與錯誤訊息。問題範本目前為簡中。
