Requires **iOS / iPadOS 18 or later**. Download on a Windows PC or Mac. No GitHub account is needed.

## Three steps

1. **Click the link above** and wait for your browser to finish downloading.
2. **Find the file** in Downloads: `simo-0.1.3-build36-unsigned.ipa`. You can also use “Show in folder” or “Show in Finder” in your browser's download list.
3. **Sign and install it** by dragging the IPA into Sideloadly and following the [installation guide](INSTALL.md). `unsigned` means the file still needs signing; the installation tool handles that step.

**Updating an existing installation:** use the same Apple Account, signing tool and app identifier to install over the existing app. **Do not uninstall it first.**

## If something goes wrong

| Problem | What to do |

| The link does nothing or the download fails | Check your browser's download list and retry. Alternatively, open the [release page](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/tag/v0.1.3) and choose the file ending in `.ipa` under `Assets` |

| Double-clicking the IPA does not install it | Drag it into Sideloadly and follow the [installation guide](INSTALL.md) |
