Both downloads are unsigned IPAs and require self-signing. These are two release choices for the same app.

**The beta is a test release. Restoring a backup replaces the entire current library; it does not merge libraries. Full restore on a physical device and use with a household NAS have not completed acceptance testing.** Keep important originals and the existing app. [Beta scope and limits — Simplified Chinese](../../RELEASE_BUILD38.md)

Requires **iOS / iPadOS 18 or later**. Download on a Windows PC or Mac. No GitHub account is needed.

## Three steps

1. **Choose a version above and click its IPA link**, then wait for your browser to finish downloading.
2. **Find the selected version’s `.ipa` file** in Downloads. You can also use “Show in folder” or “Show in Finder” in your browser’s download list.
3. **Sign and install it** by dragging the IPA into Sideloadly and following the [installation guide](INSTALL.md). `unsigned` means the file still needs signing; the installation tool handles that step.

**Updating an existing installation:** use the same Apple Account, signing tool and app identifier to install over the existing app. **Do not uninstall it first.**

## If something goes wrong

| Problem | What to do |
| --- | --- |
| The link does nothing or the download fails | Check your browser's download list and retry. Alternatively, open the [release page](https://github.com/Reyanna0o0/Simo-soundplayer/releases) and choose the file ending in `.ipa` under `Assets` |
| You cannot find the downloaded file | Use “Show in folder” or “Show in Finder” in the browser's download list |
| Double-clicking the IPA does not install it | Drag it into Sideloadly and follow the [installation guide](INSTALL.md) |
| You downloaded it on your phone | This Sideloadly workflow needs a computer; open the same download link there |

For further help, [report the issue](https://github.com/Reyanna0o0/Simo-soundplayer/issues/new?template=bug-report.yml) with your device and the error message. The issue template is in Simplified Chinese.
