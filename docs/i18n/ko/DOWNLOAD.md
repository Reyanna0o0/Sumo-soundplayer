# Sumo 다운로드

[简体中文](../../DOWNLOAD.md) · [繁體中文](../zh-Hant/DOWNLOAD.md) · [English](../en/DOWNLOAD.md) · [日本語](../ja/DOWNLOAD.md) · **한국어**

**[IPA 다운로드 · v0.1.4 (build 37)](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/download/v0.1.4/simo-0.1.4-build37-unsigned.ipa)**

이번 버전은 스피커 재생 보호를 기본으로 켜고 백그라운드 재개 조건을 개선한 별도 새 버전 **v0.1.4 / build 37**입니다. build 36의 같은 이름 파일을 교체하지 않습니다. 원래 Apple 계정, 서명 설정과 앱 식별자로 덮어쓰고 **기존 앱을 먼저 삭제하지 마세요**. [변경 내용 — 중국어 간체](../../RELEASE_BUILD37.md)

**iOS / iPadOS 18 이상**이 필요합니다. Windows PC 또는 Mac에서 다운로드하세요. GitHub 계정은 필요하지 않습니다.

## 세 단계로 진행하세요

1. **위 다운로드 링크를 클릭**하고 브라우저에 완료 표시가 나타날 때까지 기다립니다.
2. **설치 파일을 찾습니다**. 다운로드 폴더에서 `simo-0.1.4-build37-unsigned.ipa`를 확인하세요. 브라우저의 다운로드 목록에서 「폴더에 표시」 또는 「Finder에서 보기」를 눌러도 됩니다.
3. **서명한 뒤 설치합니다**. IPA를 Sideloadly로 드래그하고 [설치 안내](INSTALL.md)를 따라 주세요. `unsigned`는 아직 서명되지 않았다는 뜻이며, 설치 도구가 서명을 처리합니다.

**기존 앱을 업데이트할 때**는 동일한 Apple 계정, 서명 도구와 앱 식별자로 덮어쓰세요. **기존 앱을 먼저 삭제하지 마세요.**

## 문제가 생겼을 때

| 상황 | 해결 방법 |
| --- | --- |
| 링크가 반응하지 않거나 다운로드에 실패함 | 브라우저 다운로드 목록을 확인하고 다시 시도하세요. [버전 페이지](https://github.com/Reyanna0o0/Sumo-soundplayer/releases/tag/v0.1.4)의 `Assets`에서 `.ipa`로 끝나는 파일을 선택해도 됩니다 |
| 다운로드한 파일을 찾을 수 없음 | 브라우저 다운로드 목록에서 「폴더에 표시」 또는 「Finder에서 보기」를 선택하세요 |
| IPA를 두 번 클릭해도 설치되지 않음 | Sideloadly로 드래그한 뒤 [설치 안내](INSTALL.md)를 따라 주세요 |
| 휴대전화에 다운로드함 | 이 Sideloadly 설치 절차에는 컴퓨터가 필요합니다. 컴퓨터에서 같은 링크를 열어 다운로드하세요 |

추가 도움이 필요하면 기기와 오류 메시지를 적어 [문제를 보고](https://github.com/Reyanna0o0/Sumo-soundplayer/issues/new?template=bug-report.yml)해 주세요. 보고 양식은 중국어 간체입니다.
