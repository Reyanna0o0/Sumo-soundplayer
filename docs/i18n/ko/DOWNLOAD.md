두 파일 모두 서명되지 않은 IPA이므로 직접 서명해야 합니다. 같은 앱의 두 릴리스 중 하나를 선택할 수 있습니다.

**베타판은 테스트 버전입니다. 백업 복원은 현재 라이브러리 전체를 교체하며, 병합하지 않습니다. 실제 기기에서의 전체 복원과 가정용 NAS 사용은 아직 인수 검증을 마치지 않았습니다.** 중요한 원본 파일과 기존 앱을 보관하세요. [베타판 지원 범위와 제한 — 중국어 간체](../../RELEASE_BUILD38.md)

**iOS / iPadOS 18 이상**이 필요합니다. Windows PC 또는 Mac에서 다운로드하세요. GitHub 계정은 필요하지 않습니다.

## 세 단계로 진행하세요

1. **위에서 버전을 선택하고 해당 IPA 링크를 클릭**한 뒤 다운로드가 완료될 때까지 기다립니다.
2. **선택한 버전의 `.ipa` 파일을 찾습니다**. 다운로드 폴더를 열거나 브라우저 다운로드 목록에서 「폴더에 표시」 또는 「Finder에서 보기」를 선택하세요.
3. **서명한 뒤 설치합니다**. IPA를 Sideloadly로 드래그하고 [설치 안내](INSTALL.md)를 따라 주세요. `unsigned`는 아직 서명되지 않았다는 뜻이며, 설치 도구가 서명을 처리합니다.

**기존 앱을 업데이트할 때**는 동일한 Apple 계정, 서명 도구와 앱 식별자로 덮어쓰세요. **기존 앱을 먼저 삭제하지 마세요.**

## 문제가 생겼을 때

| 상황 | 해결 방법 |
| --- | --- |
| 링크가 반응하지 않거나 다운로드에 실패함 | 브라우저 다운로드 목록을 확인하고 다시 시도하세요. [버전 페이지](https://github.com/Reyanna0o0/Simo-soundplayer/releases)의 `Assets`에서 `.ipa`로 끝나는 파일을 선택해도 됩니다 |
| 다운로드한 파일을 찾을 수 없음 | 브라우저 다운로드 목록에서 「폴더에 표시」 또는 「Finder에서 보기」를 선택하세요 |
| IPA를 두 번 클릭해도 설치되지 않음 | Sideloadly로 드래그한 뒤 [설치 안내](INSTALL.md)를 따라 주세요 |
| 휴대전화에 다운로드함 | 이 Sideloadly 설치 절차에는 컴퓨터가 필요합니다. 컴퓨터에서 같은 링크를 열어 다운로드하세요 |

추가 도움이 필요하면 기기와 오류 메시지를 적어 [문제를 보고](https://github.com/Reyanna0o0/Simo-soundplayer/issues/new?template=bug-report.yml)해 주세요. 보고 양식은 중국어 간체입니다.
