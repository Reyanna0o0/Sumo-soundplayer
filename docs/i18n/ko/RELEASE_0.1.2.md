## 창작자 아바타 자르기

- 창작자 편집 화면에서 사진이나 파일로 아바타를 선택하면 「아바타 자르기」가 열립니다.
- 드래그로 위치를 조절하고 두 손가락 또는 슬라이더로 확대·축소합니다. 원형 프레임으로 표시 범위를 확인하고, 초기화로 처음 중앙 위치로 돌아갈 수 있습니다.
- 「사용」을 누른 다음 창작자 정보를 저장합니다. 자르기를 취소하면 현재 아바타를 유지하며, 편집 화면 전체를 취소하면 이번 변경 사항을 버립니다.
- 이 아바타를 이어받는 창작자 표지나 통화 화면도 선택한 범위를 사용합니다. 작품 표지는 기존 4:3 자르기를 유지합니다.

## 검증 범위

- 기기용·시뮬레이터용 Release 빌드, 리소스 확인과 앱의 5개 언어 문구 검사를 통과했습니다.
- 시뮬레이터에서 사진 선택, 취소, 드래그, 두 손가락·슬라이더 확대, 초기화, 저장, 반복 교체 후 편집 취소를 확인했습니다. 앱 내부에서 실행한 검사로 실제 자른 영역, 정사각형 출력, 4:3 표지 호환, 아바타 상속과 임시 파일 정리를 확인했습니다.
- 독립 시뮬레이터와 합성 자료를 사용했으며 사용자의 휴대전화는 조작하지 않았습니다. 파일 선택도 같은 자르기 처리를 사용하지만, 시스템 파일 화면에서 탐색·선택한 후 자르기까지 이어지는 전체 UI 절차는 검증하지 않았습니다. 오래된 사진, iCloud 다운로드, 외부 파일 서비스와 iPad 배치는 실기기 확인이 필요합니다.
- 코어 검사 3755개와 선택 세션 검사 9개는 build 34의 결과입니다. build 35에서는 코어와 데이터베이스 구조를 바꾸지 않았으며 아바타 자르기를 추가로 검증했습니다. [상세 검증 기록 — 중국어 간체](../../RELEASE_STATUS.md)

## 첨부 파일

일반 설치는 `.ipa`를 받아 직접 서명하면 됩니다. `.ipa.json`과 `.ipa.sha256`에는 빌드 출처와 체크섬이 있습니다. `simo-0.1.2-build35-source.zip`은 대응 소스, 타사 소스 자료와 재빌드 안내를 제공합니다. `LICENSE.txt`와 `SHA256SUMS.txt`는 라이선스와 첨부 파일 검증 목록입니다. build 33과 34의 기존 첨부 파일도 계속 보관됩니다.
