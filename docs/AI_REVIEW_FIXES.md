# AI 使用反馈修复与复测交接

2026-11-23。开发分支包含以下修复，正式 Release 仍为 v0.1.2 / build 35。请从当前源码构建；历史 IPA 不包含这些改动。

## 已修改，等待操作回归

- 导入结果：所有完成状态 5 秒后清除，切到其他标签不重置计时；警告及失败提示可关闭，长文字区域可滚动。
- 双语字幕：文件夹与 ZIP 共用保守配对规则，同目录、同格式、同名且恰好两种语言时合并为原文与译文；歧义项留给手选。保留原有音频版本归属规则。不迁移或覆盖已存在的字幕、人工编辑和关闭状态。
- ZIP 文件名：未设置 UTF-8 标志但字节是有效 UTF-8 时，按 UTF-8 保存。ZIPFoundation 条目校验仍使用其原始解码；Unicode 扩展字段优先，路径安全、重复路径与 CRC 校验保留。未增加 GBK 自动猜测。
- 导入预览：显示可解析字幕文件数、封面数及文件名；展开未自动收录文件，说明未匹配或无法解析时间字幕的原因。预览是扫描结果，最终导入仍可能受权限和文件变化影响。
- 大字号：空状态可滚动，库标题与操作栏在辅助字号下上下排列，封面网格改为单列；语言选择值可换行。
- 播放器：操作按钮改为三列、辅助字号两列，文字可换行；工具按钮和摘选标记补充触控范围、明确读屏名称。
- 外观：四种选择同屏两列。保留米白默认值与用户已有选择。
- 字幕工具：长菜单拆成显示/编辑子菜单，原文与译文另有直接入口。
- iPad：通用列表最大宽度 860 pt，封面网格内容最大宽度 1000 pt；宽屏播放器复用已有左右布局。原有自适应多列网格保留，单作品夹具不能证明多列失效。
- 时长：短于一分钟的封面卡显示秒；详情曲目秒数改为四舍五入，避免 9 秒显示 8 秒。回顾中的整分钟统计是摘要，未改为秒级显示。
- 文件位置只显示文件夹名称；加入播放列表的标题使用当前外观文字颜色。
- 同作品播放自然结束时提示模拟通话已结束；保留沉浸通话文案。原报告无法排除测试音轨结束导致返回，不能据此宣称视频切换故障已复现或根治。

## DeepSeek 复测顺序

1. 独立测试库分别导入文件夹与 macOS ZIP，核对中日韩文件名、双语字幕内容、关闭原文/译文、预览数量及未收录台本名称。两条路径用新导入作品；旧字幕不会被自动重写。
2. 导入含未匹配文件的资料，立即切统计页，等待 5 秒回库，确认提示已消失；另检查手动关闭。
3. 390 pt + AX-XXXL：空状态滚到导入按钮；库标题、卡片、详情最后一行、迷你播放器、设置语言与外观均可读可操作。
4. 日语 medium：播放器按钮无截断，字幕工具每个子菜单首尾可触达；加入列表标题对比清晰。
5. iPad 13 英寸使用多部作品，检查自适应列数、居中列表和左右播放器布局；检查横竖屏切换。
6. 通话使用至少 3 分钟音轨，持续播放时反复切语音/视频；再单独跳到队列末尾，确认自然结束提示。若仍异常，请给出操作时间点、当前曲目剩余秒数和截图。
7. 旧资料回归：编辑过的字幕、关闭字幕状态、分组名、统计、原媒体文件和用户外观选择应保留。

- 原报告中 VoiceOver 的 FaceTime / nan，以及大字号全屏字幕说明末行与所有触控目标，仍需提供精确元素与操作回归；本轮未把它们标为已解决。
