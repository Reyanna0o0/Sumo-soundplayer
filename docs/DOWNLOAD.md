**[点击下载 IPA · v0.1.4（build 37）](https://github.com/Reyanna0o0/Simo-soundplayer/releases/download/v0.1.4/simo-0.1.4-build37-unsigned.ipa)**

本次为 **v0.1.4 / build 37**，新增默认开启的外放保护，并修正后台中断后的恢复条件；它是独立新版本，不再替换 build 36 的同名附件。沿用原 Apple 账户、签名设置和应用标识覆盖安装，**不要先卸载旧版**。[更新说明](RELEASE_BUILD37.md)

适用于 **iOS / iPadOS 18 或更新版本**。在 Windows 或 Mac 电脑上下载，无需登录 GitHub。

## 三步完成

1. **点击上方下载链接**，等待浏览器显示下载完成。
2. **找到安装包**：打开电脑的「下载 / Downloads」文件夹，找到 `simo-0.1.4-build37-unsigned.ipa`。也可以在浏览器下载列表中点「在文件夹中显示」或「在访达中显示」。
3. **签名安装**：把 IPA 拖进 Sideloadly，按[安装教程](INSTALL.md#方式一sideloadlywindows--mac)完成。文件名中的 `unsigned` 表示还需要签名，由安装工具处理即可。

**已经装过厮磨？** 用原 Apple 账户、原签名工具和原应用标识覆盖安装，**不要先卸载旧版**。

## 遇到问题

| 情况 | 怎么做 |
| --- | --- |
| 点下载链接没反应或下载失败 | 查看浏览器下载列表并重试；也可打开[版本页](https://github.com/Reyanna0o0/Simo-soundplayer/releases/tag/v0.1.4)，在 `Assets`（附件）中点击以 `.ipa` 结尾的文件 |
| 找不到下载好的文件 | 打开浏览器下载列表，点文件旁的「在文件夹中显示」或「在访达中显示」 |
| 双击 IPA 无法安装 | 把它拖进 Sideloadly，再按[安装教程](INSTALL.md#方式一sideloadlywindows--mac)操作 |
| 下载到了手机上 | 这套 Sideloadly 安装步骤需要电脑；在电脑上打开同一个链接下载即可 |

需要进一步帮助时，可[反馈问题](https://github.com/Reyanna0o0/Simo-soundplayer/issues/new?template=bug-report.yml)，说明设备和报错文字。
