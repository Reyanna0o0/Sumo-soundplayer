系统迁移可能保留作品资料，即使 App 当时无法打开；缺少原文件或访问授权时，作品仍可显示而目录刷新失败。因此侧载安装、App 数据、原始媒体和授权需分别核对。[换机与无法启动排查](MIGRATION.md)

以下为此前正式版本的记录。v0.1.4（build 37）更新于 2026-11-24，目标 iOS / iPadOS 18 起；此前 v0.1.3 / build 36 的重建与附件替换记录保留为历史。

- 最终 iPhoneSimulator Release（arm64 / x86_64）与 iPhoneOS Release 构建通过，隔离模拟器安装与启动完成。当前记录没有把编译通过或启动成功扩展为触控界面与真实音频行为均通过。
- 新增外放保护的设置、静音状态和解除按钮均具备五语文案；短控件沿用局部字号上限，说明文字保留放大。
- 源码覆盖普通音频、正式视频、视频附件预览、通话和开屏语音。音频引擎用独立最终输出静音门，避免淡入淡出覆盖静音；视频与开屏分别接入自身静音控制。保护不写系统音量，解除静音不主动启动播放。
