- 从照片或文件选择创作者头像后进入裁剪页；圆形预览，支持拖动、双指缩放、滑块和复位。确认「使用」后才替换编辑草稿，最终「保存」才写入创作者资料。
- 裁剪结果保存为正方形图片。继承创作者头像的通话外观和封面使用该范围；原作品封面的 4:3 裁剪与保留原图机制不变。
- 隔离模拟器的 3 项界面流程通过：照片选取后取消裁剪再保存原头像；拖动 / 双指 / 滑块 / 复位并保存；连续更换后重新进入裁剪、取消裁剪和整个编辑页。
- App Hosted 验证实际输出所选颜色区域、正方形尺寸、继承时读取裁剪结果、4:3 封面尺寸及原图保留；取消裁剪后的数据库引用不变，临时输入清理且本地输入文件字节不变。最终重新打开测试库，已保存的 336 × 336 头像仍在，5 张被引用图片可读，无多余草稿文件。
- iPhoneOS Release、iPhoneSimulator Release（arm64 / x86_64）构建与资源核对通过；1349 个文案键覆盖 5 种语言。没有核心层或数据库结构改动；3755 项核心与 9 项选择会话检查为 build 34 的已通过记录，本轮没有把它们重复计为新测试。
- 本轮沿用独立模拟器和合成资料，未操作用户手机。文件入口共用同一裁剪流程，真实文件读取与清理已检查，但系统文件浏览选中至裁剪的完整界面链路仍未验证；build 34 所列系统文件浏览、旧照片 / iCloud 与 iPad 验证边界继续适用。

## build 34：照片与文件选择稳定性修补

- 针对 build 33 播放期间编辑图片时图库反复载入、跳回顶部及关闭无效的反馈，将图片选择会话移出懒加载表单行，由编辑器常驻页面持有。系统选择器只在创建时配置，播放与统计刷新不重新配置图库。
- 创作者头像和封面、作品封面，以及作品／创作者／个人通话资料入口共用稳定会话；固定目标、阻止重复打开及旧回调串入。选择完成并关闭系统面板后才复制文件或进入裁剪；取消保留原资料并清理未保存草稿。
- 文件面板保留顶部安全区域。字幕页与作品详情取消文件选择时直接返回。
- 核心 SelfTest：3755 项通过、0 项失败；新增选择会话与图片读取检查：9 项通过、0 项失败。
- 完整 iPhoneOS Release 和 iPhoneSimulator Release（arm64／x86_64）构建通过；本地资源检查通过。应用标识沿用 build 33，数据库结构没有更改。
- 独立 iPhone 模拟器使用 360 张编号合成照片（另有 6 张系统照片）和两首 900 秒测试音频。创作者、作品与个人头像的照片入口通过滚动、关闭 / 重开、选图、裁剪、保存 / 取消检查；代表入口在播放或暂停状态持续滚动至少 65 秒。相关图片文件入口取消与重开通过。
- App Hosted 检查通过：文件选择回调在面板关闭后读取真实 PNG，图片可解码，取消清理新图片且原文件内容不变；编辑后 5 张被引用图片均有效、取消保留原图且没有多余草稿。审计时收听统计累计 1651 秒，确认选图测试伴随实际播放与统计更新。
- 文件深层浏览存在验证限制：此模拟器中选择器和系统「文件」App 本身都无法进入同一测试文件夹，系统日志同时记录导航栈异常。未完成文件浏览选中至裁剪的完整界面链路，不把文件回调后的读取检查等同于端到端选择通过。视频 / ZIP 类型菜单切换、多选组合及原生文件夹面板关闭控件也未完成界面验收；已代码检查类型及选择模式。
- 手机上的大量旧照片、iCloud 下载、第三方文件服务、后台切歌后取消字幕以及 iPad 布局尚未在本轮实测。此次没有操作用户手机、媒体或数据库，不据模拟器结果宣称真机故障已完全消失。
